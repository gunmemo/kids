# 마법 색칠나라

어린이를 위한 Vite + React + Tailwind CSS 색칠 앱.

```sh
pnpm install
pnpm dev
pnpm build
pnpm test
```

동물·사물 및 탈것·요정·공주 각 20종의 PNG 도안 80종과 기존 기본 SVG 6종을 제공합니다. 주제별 목록에서 도안을 선택하고 캔버스 영역 채우기, 구획 지우개, 색상 선택, 실행 취소/다시 실행(최대 30단계), 전체 지우기, 로컬 갤러리 및 PNG 다운로드를 사용할 수 있습니다.

도안 파일은 `public/artwork/`, 목록은 `artwork/catalog.json`에 있습니다. 생성 프롬프트와 검수 방법은 [도안 제작·검수 기록](artwork/README.md), 자동 검사 결과는 `artwork/qa-results.json`을 참고하세요.

색상 선택 시 영어 음성 파일이 재생되며 상단 스피커 버튼으로 끌 수 있습니다. ‘완성했어요!’ 버튼은 작품 미리보기, 축하 멜로디와 색종이 효과를 표시합니다. 완료 화면에서 갤러리 저장, PNG 다운로드, 계속 색칠하기를 선택할 수 있습니다. 동작 줄이기 설정에서는 축하 애니메이션을 생략합니다. `effects-check.cjs`로 이 흐름을 검증합니다 (`APP_URL`로 검사 서버 주소 지정 가능).

색상 버튼은 Runway로 생성한 Niki 목소리의 영어 색 이름 MP3 14개를 재생합니다. AI로 생성된 음성이며 파일은 `public/audio/colors/`, 제작 기록은 해당 폴더의 `manifest.json`에 있습니다. 기기 기본 TTS와 외부 서비스 실시간 호출을 사용하지 않습니다. 연속 선택 시 이전 음성을 중단하고, 음소거도 재생을 즉시 멈춥니다. 음성과 겹치던 색상 선택 전자음은 제거했습니다. `audio-check.cjs`는 14개 파일의 디코딩·길이·무음 여부를, `effects-check.cjs`는 브라우저에서 실제 MP3 재생과 음소거를 검증합니다.

사용자가 제공한 태블릿 UI 명세를 적용했습니다. 가로 고정 화면에 상단 도안 바로가기와 편집 도구, 중앙 보드, 오른쪽 14색 팔레트를 배치합니다. 주요 버튼은 최소 56px이며 세로 방향에서는 회전 안내를 표시합니다. 도안과 작품 목록은 8개씩 페이지를 넘깁니다. 채우기 터치에 반짝임·팝 효과음을, 색상 선택에 바운스와 금색 링을 표시합니다. 화면 스크롤·확대 제스처·텍스트 선택을 차단합니다.

`browser-check.cjs`는 `tablet-check.cjs`, `effects-check.cjs`, `drawing-tools-check.cjs`를 실행합니다. 1280×800, 1280×720, 1024×640의 Edge 터치 에뮬레이션에서 화면 넘침, 버튼 크기, 채우기/지우개, 실행 취소, 초기화 확인, 도안 선택, 완성과 오디오 연결을 검증했습니다. 실제 Android 기기의 스피커 출력은 별도 확인이 필요합니다.

이번 변경 범위는 UI와 인터랙션입니다. PNG 80종을 SVG 구획으로 변환하지 않았으며, 기본 SVG도 기존처럼 캔버스에 렌더링하여 채웁니다. 독립 path를 사용하는 2층 SVG 엔진은 포함하지 않습니다.

채우기는 원본 도안에서 만든 고정 구획 맵을 사용합니다. 회색 경계 안쪽까지 색을 적용하고 원본 선의 밝기를 곱해 합성하므로, 재색칠할 때 이전 색 테두리가 남지 않고 지우개는 원본 픽셀을 복원합니다. 65 미만의 어두운 선 픽셀은 변경하지 않습니다. `ribbon-check.cjs`는 공주 리본 5개 구획의 경계 채색, 다른 구획·외곽선 보존, 재색칠 후 복원을 검증합니다.

갤러리는 해당 브라우저의 localStorage에 최근 24개까지 보관됩니다. 브라우저 데이터를 삭제하면 없어지므로 중요한 그림은 PNG로 내려받으세요. Android 태블릿 브라우저의 가로 화면용 웹 앱이며, APK 및 Android 시스템 사진 갤러리 직접 저장은 포함하지 않습니다.

오른쪽 도구 패널에 색 채우기·자유그림 펜·스탬프·구획 지우개가 있습니다. 별·하트·꽃 스탬프와 3단계 도구 크기를 제공하며, 펜·스탬프 사용 중 색을 바꿔도 도구가 유지됩니다. 상단 종이+ 버튼은 빈 도화지를 엽니다. 펜 한 획과 스탬프 한 번은 각각 실행 취소 한 단계로 기록됩니다. 지우개는 기존과 같이 원본 구획 단위로 복원합니다.

자유그림 펜을 선택하면 크레용·네온 음색을 고를 수 있습니다. 크레용은 필터를 거친 작은 백색 소음, 네온은 상승하는 실로폰풍 아르페지오를 Web Audio API로 합성합니다. 움직임마다 짧은 소리를 재생하고 획 종료·취소·음소거·창 이탈 시 중단합니다. 일반 버튼은 팝 소리를 내며, 색상 버튼의 영어 음성과 완료 징글은 유지합니다. 크레용은 일반 선, 네온은 색 빛 번짐·밝은 중심선·별 하이라이트를 그립니다. `brush-audio-check.cjs`는 잡음 소스, 상승 음정, 중단과 음소거, 비동기 오디오 재개 취소 및 작은 태블릿 레이아웃을 검사합니다.

아동 터치 안전 개선: 초기화는 편집 버튼 그룹에서 분리되어 1.5초 길게 누른 뒤 확인창이 열립니다. 원형 진행 표시를 제공하며 손 떼기·버튼 밖 이동·포인터 취소·포커스 이탈 시 취소합니다. 키보드 Space/Enter 길게 누르기도 지원합니다. 오른쪽 패널은 236px, 색상 칩은 64px/간격 12px이며 흰색에는 2px 외곽선이 있습니다. 도구 크기는 도화지 아래로 이동했습니다. 완료 버튼의 별은 34px이며 반복 바운스는 동작 줄이기 설정에서 꺼집니다. `ui-layout-check.cjs`에서 크기·선택 표시·길게 누르기 취소 및 접근성 동작을 검증합니다.

브러시 선택은 글씨 대신 큰 아이콘을 표시하며 접근성 이름을 유지합니다. 네온 드로잉 중 별 파티클이 나타나고, 캔버스에 그려진 빛 번짐과 하이라이트는 실행 취소·다시 실행 및 PNG 저장에도 포함됩니다. `neon-check.cjs`로 아이콘, 네온 픽셀, 파티클, 기록 복원과 완성 미리보기를 검사합니다.

네온은 획 전체를 원래 화면 위에 다시 합성하여 이벤트 밀도에 따른 중첩 번짐을 방지합니다. 1단계는 선택 색상 계열의 고채도 발광(두께 1.5배, blur 20, alpha 0.7), 2단계는 순백 코어(두께 0.4배, blur 8)입니다. 마지막에 원본 도안을 darken 합성하여 검은 외곽선을 보존하며 저장 이미지에도 적용합니다. `neon-render-check.cjs`에서 순백 코어, 채도, 입력 밀도 독립성, 원본 검은 선 보존을 확인합니다.

도안 갤러리는 큰 이모지 카테고리, 설명 없는 파스텔 썸네일 8개, 56px 화살표와 페이지 도트를 제공합니다. 좌우 스와이프(55px 이상)로 페이지를 넘기며 드래그 뒤 도안 선택을 막습니다. 카드 이름은 스크린리더용 접근성 이름으로 유지합니다. `gallery-check.cjs`에서 화면 크기, 페이지 경계, 카테고리 전환과 스와이프 오선택 방지를 검사합니다.

헤더는 왼쪽 로고·도안 책 버튼, 가운데 빈 공간, 오른쪽 흰색 컨트롤 캡슐의 3구역입니다. 상단 버튼은 요청에 따라 48px 원형으로 통일했고 도안 바로가기와 제목을 제거했습니다. 휴지통 아이콘은 글씨 없이 원형 1.5초 진행 표시와 확인창을 유지합니다. 빈 도화지는 도안 갤러리의 기본 카테고리 안 연필 카드로 이동했습니다. `header-check.cjs`로 구역과 버튼 크기를 확인합니다.

초기화 확인창은 현재 그림의 140×100 미리보기와 두 개의 큰 카드로 구성됩니다. 앨범에 쏙은 저장 성공 후 도안 목록을 열고, 새 도화지는 현재 도안을 초기화합니다. 닫기/계속 그리기는 그림을 유지합니다. 저장 실패 시 그림을 유지하며 다운로드 안내로 이동합니다. `reset-choice-check.cjs`에서 미리보기 일치, 저장·목록 전환, 초기화·실행 취소와 저장 실패를 검증합니다.

선 두께 3단계 선택은 오른쪽 도구 모음 하단에 배치합니다. 높이 720px 이하 화면에서는 도구 모음 간격을 줄여 모든 선택 버튼이 화면 안에 들어오게 합니다.

카테고리 탭은 글씨 없이 44px 그림 아이콘과 강조 배경·탄성 효과를 사용합니다. 자유 그리기 탭과 빈 도화지 카드는 흰 스케치북·컬러 크레파스 SVG로 표시합니다. 기본 SVG 썸네일만 선을 8px로 굵게 하며 실제 색칠 도안은 유지합니다. 빠른 30px 이상 스와이프도 인식하고 드래그 시 방향 피드백을 제공합니다.

우측 도구는 컬러 SVG 물감통·크레파스·도장으로 표시합니다. 브러시에만 음색·두께, 스탬프에만 모양 옵션을 보여주며 페인트통은 색상에 집중합니다. 선택 색은 체크 대신 1.15배 확대와 흰 테두리로 강조합니다. 상단 도안 버튼은 60px 스케치북, 하단은 액자·트로피 아이콘입니다. 완료는 기존 전체 화면 색종이 및 축하 사운드를 재사용합니다. `toolbar-check.cjs`로 옵션 분리와 48px 이상 터치 크기 및 작은 태블릿 배치를 확인합니다.

완성 화면은 12px 골드 액자와 확대 등장, 96~108px 컬러 트로피, 전체 화면 60개 색종이 애니메이션과 기존 축하 사운드를 제공합니다. 완료 화면의 저장 액션은 내 갤러리에 쏙 하나로 통합하고 더 그릴래로 복귀합니다. 저장은 앱의 localStorage 갤러리이며 기기 사진첩 직접 저장은 아닙니다. 색종이는 기존 CSS 효과를 확장했으며 동작 줄이기 설정에서는 숨깁니다. `celebration-check.cjs`와 `effects-check.cjs`에서 배치·저장·돌아가기·음소거·동작 줄이기를 확인합니다.

직업과 역할 카테고리에 SVG 도안 20개를 추가했습니다: 의사, 소방관, 경찰관, 요리사, 제빵사, 선생님, 과학자, 우주비행사, 비행기 조종사, 농부, 정원사, 건축가, 목수, 정비사, 화가, 음악가, 수의사, 우편 배달원, 환경 지킴이, 구조대원. 파일은 public/artwork/roles-01.svg부터 roles-20.svg까지이며 재생성 스크립트는 artwork/create-roles.cjs입니다. roles-check.cjs로 디코딩·넓은 색칠 구획·카테고리 페이지·캔버스 로딩을 검증하고 artwork/roles-review.png에 전체 검수 이미지를 보관했습니다.

직업 도안 재제작: 사용자 지정 20개 직업(소방관·의사·우주비행사·요리사·경찰관·정원사·선생님·수의사·조종사·화가·트럭 운전사·사서·건축가·과학자·패션 디자이너·축구 선수·가수·무용가·농부·어부)을 내장 이미지 생성으로 각각 제작했습니다. 단순 SVG 대신 기존 도안과 어울리는 작업 장면 PNG를 사용합니다. 전체 시각 검수와 색칠 구획 검사 완료. 이전 SVG 생성 스크립트는 과거 자료이며 다시 실행하면 최신 목록을 덮어쓰므로 사용하지 마세요.

내 작은 갤러리는 저장 작품이 있으면 최근 작품 카드 그리드와 안내 문구를 표시하고, 없으면 빈 상태를 유지합니다. ArtworkCard(image,title,onClick)를 분리했으며 카드 클릭은 해당 작품 PNG, 하단 버튼은 현재 캔버스 PNG를 내려받습니다. saved-gallery-check.cjs는 실제 작품 저장·새로고침 후 복원·빈 상태 전환·다운로드를 검증합니다.

직업 도안 채우기 누수 보완: 원본 이미지에서 작은 끊김(700×600 기준 약 4px)을 닫은 구획 맵을 만들고, 화면 가장자리와 이어진 배경 구획은 채우지 않습니다. 실제 선화 픽셀은 변경하지 않습니다. 큰 열린 영역은 안전상 색칠되지 않을 수 있으므로 별도 도안 수정이 필요합니다. 단위 테스트는 끊긴 사각형 복구·배경 누수 방지·지우기 복원을, roles-check.cjs는 20개 실제 도안의 내부 구획 채우기와 배경 차단을 검증합니다.

크레이터 수정 검증: 이미 닫힌 작은 영역은 틈 보완 처리에서 제외해 보존합니다. 실제 우주비행사 도안 작은 구획 32곳의 채우기 검사를 통과했습니다. 이전 SVG 초안은 로컬 artwork/legacy-role-drafts로 옮겨 배포에서 제외했습니다.
